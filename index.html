How it's built

Pipeline (SystemVerilog)

  • 10G XGMII MAC, receive traffic filter, UDP/IPv4 receive with header checksum checking
  • MoldUDP64 A/B line arbitration, de-duplication and gap detection, with hardware gap re-request and a live-feed hold buffer
  • ITCH 5.0 parser → symbol table → order book (2-choice hash, 196,608 orders in UltraRAM, price ladders)
  • 5 strategies (takers and market makers), pre-trade risk checks, OUCH 4.2 encoder
  • SoupBinTCP session over a hardware TCP client with TCP/IP checksum generation; ARP responder

Clocks & implementation

  • 3 clock domains: 156.25 MHz (10G line), 250 MHz (core), 100 MHz (host / ARM)
  • Custom clock-domain-crossing IP: Gray-code async FIFOs, packet FIFOs, pulse and handshake synchronisers, with scoped timing constraints
  • 14 blocks packaged as Vivado IP-XACT IP and assembled into a validated block design
  • Static timing analysis in Vivado; the worst paths were pipelined with no latency added on the order path

Verification

  • Self-checking cocotb / Verilator testbenches against Python golden models and scapy
  • QuestaSim SystemVerilog testbenches with assertions
  • Full-day replays of real NASDAQ ITCH, bit-exact against a reference order book
  • Error injection: lossy feed lines, dropped packets, lost retransmissions, TCP loss
  • 33-step automated regression
